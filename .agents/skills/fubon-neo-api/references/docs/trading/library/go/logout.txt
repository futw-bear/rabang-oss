## 請求範例[​](#請求範例 "Direct link to 請求範例")

```go
package main

import (
	"fmt"
	"fubon"
)

sdk := fubon.NewFubonCore()

// login ...

logoutResp, err := sdk.Logout()
fmt.Println("Logout result: ", logoutResp)

```
